## 🧠 Overview

ChatCord is a personal fork of the classic Brad Traversy demo app. It enables users to join chat rooms and exchange messages in real time using Socket.io.  
Inspired by the Traversy tutorial: Real-time chat app with rooms using Node, Express and WebSockets :contentReference[oaicite:11]{index=11}.

---

## 🛠️ Built With

- **Node.js** – backend server  
- **Express** – web framework  
- **Socket.io** – real-time communication  
- **HTML, CSS, JavaScript** – front-end
